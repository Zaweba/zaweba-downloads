# Zaweba downloads

**Zaweba** is a suite of private, offline-first Windows apps: art, video, music, documents, files, web and system
tools. No adverts, no tracking, no account. This repository hosts the downloads; everything else, including
screenshots and help, is on **[www.zaweba.com](https://www.zaweba.com/)**.

## Download

Every app is one ZIP: unzip it anywhere and double-click the exe. There is no installer, and most apps need no
administrator rights. Windows 10 or 11, 64-bit.

Each app's release page ([Releases](https://github.com/Zaweba/zaweba-downloads/releases)) has its install notes, requirements and the
ZIP's SHA-256.

## Beta

1 of these apps are **betas**: Free while Zaweba is in beta. When it launches, beta users get 12 months free, then 50% off for 5 years. Prices will be confirmed at launch. Please tell us what breaks and what you would like:
[send feedback](https://www.zaweba.com/feedback/) (or Help › Send feedback in any app).

**Windows may warn you the first time.** The apps aren't signed (approved) for Windows yet, so SmartScreen may show
"Windows protected your PC". Click **More info**, then **Run anyway**. You only need to do this once. Signed versions
are coming soon.
